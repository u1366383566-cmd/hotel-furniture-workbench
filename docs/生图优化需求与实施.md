# 生图工具优化：美工交流需求

## 需求对齐

- 同一风格的全景需要有明显的核心家具造型、材质和配色差异，同时保持系列特征；美工反馈的“95%相似”是主观观察，并非测量结果。
- 保留全景家具完整、清晰可辨的约束，以便从审核通过的全景提取白底家具。白底图目前不是主要问题。
- 系列规则是生成依据，用户希望扩充各字段的选项，由系统选取，而不是每次手写生图提示词。
- 风格系列入口移到额度信息下方单独展示；大量规则选项应在较短的输入框内滚动编辑。

## 本次实现

方案创建时从系列选项中随机抽取候选组合，并与同系列未淘汰的历史方案比较，优先使用重合较少的组合；智能规划参考候选及历史方案调整家具和空间。选项较少或组合接近历史方案时显示提醒。规则和设计仍按原流程冻结，白底提示词和生成链路不变。风格系列入口独立展示，规则输入框限制高度并支持滚动；AI 可按字段生成候选，经美工勾选后追加并手动保存。

## 验证边界与后续

系统可以检查候选组合是否覆盖规则，但无法据此保证生成图片的视觉差异。需要在有额度时，用同一系列的多组真实全景并排交由美工判断，记录明显重复的家具部位和提示词，再决定是否需要调整规划策略。规则选项仍应由美工检查其风格一致性和组合适配性；规则过少或选项含义相近时，轮换也不能保证差异。
