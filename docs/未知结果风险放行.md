# 未知结果风险放行

管理员可在任务额度设置中开启请求阶段超时和上游 5xx 自动按失败放行。默认关闭；开启后释放的是工作台额度占用，并不能证明上游未出图或未扣费，实际消耗可能超出工作台统计，重做可能再次计费。

自动重试是独立开关，默认关闭。开启前必须同时接受未知扣费风险。请求超时、上游 5xx、HTTP 429 和请求阶段临时连接错误按 30 秒、90 秒退避，最多自动重试两次；429 优先使用 `Retry-After`，并限制在 15～300 秒。每次尝试单独预占账本并写入 `image_generation_attempts`，不新增用户可见版本，也不消耗人工重做次数。

自动重试耗尽后，任务显示在“技术失败待确认”，批次继续处理其他任务。负责人或管理员确认风险后，可对所选任务重新开放最多两次自动重试；系统沿用原任务、提示词、视角、参考图和依赖，只重置当前自动重试轮次。

仅符合请求阶段异常、版本没有图片记录及预计文件、设计未终结、账本为预占的任务可自动释放。下载错误、响应解析错误、磁盘错误、重启恢复及不明异常仍保持原有未知或熔断处理。自动放行不清除其他未知任务，不解除人工暂停或熔断，也不自动重做。

管理员可通过 `POST /api/system/release_unknown_risk` 对符合条件的已有未知任务执行一次风险放行，传入任务 ID 和 `accept_unknown_charge: true`；该操作明确记录上游扣费未知，不冒充无扣费核验。自动及人工风险放行在管理中心显示记录，并写入审计日志。

系统不依据旧错误文本自动补发生图。请求超时或 5xx 放行后记录 `failure_stage=request_charge_unknown`，页面提示重做可能再次计费；工作线程重启也不会自动重发。只有审计记录能够核实任务和“上游扣费未知”时，迁移才回填该阶段。

文本规划的超时、连接失败和上游 5xx 是最多两次的临时重试，分别等待 15、30 秒；其他规划错误直接失败，人工重试会重置技术退避次数但保留方案纠偏次数。

图片结果已返回但下载中断时，只重试同一次结果地址，不重新发送生图请求。原图已落盘而预览失败时，使用原图最多重建两次。仍失败时保留额度：同批第一个此类设计只隔离本组，第二个出现时暂停新增派发；人工核账后按剩余待处理数决定是否恢复。生成结果地址不进入页面或日志。

整套家具白底失败时，双床和床头局部继续等待有效白底。可回选同组、同一全景下可读的历史白底，或手动重做；只有尚未发出且明确引用旧白底的配图会改绑，新白底完成后各派发一次，不用全景静默兜底。

## 长列表刷新

工作台轮询使用 `/api/designs/batch/{batch_id}/summary` 的轻量概要，不返回历史版本或完整提示词。概要响应带 ETag，未变化时返回 304；页面只替换状态修订值变化的卡片。版本图片按版本 ID 缓存 7 天，列表使用浏览器懒加载和 CSS 内容可见性优化。打开提示词或历史版本时再请求完整设计详情。
